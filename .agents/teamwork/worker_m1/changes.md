# Changes Summary - Milestone 1

## Files Created / Modified

### 1. `tools/generate_explosion_flipbook.py`
- Executable Python automation script for Blender headless execution: `blender --background --python tools/generate_explosion_flipbook.py`.
- Features:
  - CLI argument parsing with optional parameters (`--resolution`, `--frames`, `--frame-size`, `--output`, `--skip-import`).
  - Clears default scene with factory settings.
  - Emitter UV-sphere (radius 0.4m at origin) with Mantaflow Flow type `BOTH` (Fire + Smoke), behavior `INFLOW` keyframed active for frames 1-3 only, initial normal velocity 8.0 m/s with 2.5 random, fuel 1.8, surface emission 1.0, and `hide_render = True`.
  - Gas domain (6m x 6m x 6m cubic box at `(0, 0, 2.0)`) with 128 resolution divisions, time scale 1.3, reaction speed (`burning_rate = 0.65`), flame smoke 3.0, flame vorticity 0.45, domain vorticity 0.45, dissolve enabled (`dissolve_speed = 45`, `use_dissolve_smoke_log = True`), and cache type `ALL` for frames 1 to 64.
  - Principled Volume shader driven by Mantaflow `flame` attribute (through custom fire color ramp and emission multiplier 25.0) and `density` attribute (density 8.0, smoke albedo `(0.28, 0.27, 0.26)`).
  - Directional sun lighting providing volumetric rim and fill shading to the expanding smoke billows.
  - Orthographic camera at `(0, -7.5, 2.0)` with rotation `(90°, 0°, 0°)` and orthographic scale 7.0 for clipping-free coverage.
  - Transparent film EEVEE renderer outputting 256x256 RGBA frames.
  - Spritesheet assembly module supporting Pillow (embedded or system python3) and ImageMagick `montage` with `PNG32:` fallback.
  - Automatic invocation of `godot --headless --editor --quit` to generate engine `.import` and UID files.
  - Clean `try...finally` teardown ensuring all intermediate simulation cache and frame files in `/tmp` are purged.
